# Website Curriculum Vitae (CV) Digital

Proyek ini adalah website CV digital interaktif yang dibuat menggunakan HTML5, CSS3, dan di-containerize menggunakan Docker.

## Fitur Utama
- **HTML Semantik:** Penggunaan header, nav, main, section, dan footer.
- **Styling CSS:** Penggunaan Flexbox untuk profil & navigasi, serta CSS Grid untuk bagian Skills dan Portfolio.
- **Dockerized:** Dijalankan dengan web server Nginx di port 8080.

   ```bash
   docker build -t cv-digital .
